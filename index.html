같은 네트워크의 Windows PC 두 대를 키보드와 마우스 하나로 조종합니다. 커서를 화면 끝으로 밀면 상대 PC로 넘어가고, 상대 화면을 보며 조종하거나 파일을 주고받을 수 있습니다.

  • C#
  • .NET 10
  • WPF
  • Win32 API
  • TCP/UDP
  • SQLite
구성2인 팀. 입력 처리, 조종 세션, 화면, 로컬 DB, 테스트 담당

링크github.com/leeduram/MultiPcKvm

핵심 구현

  • 입력 공유. 키보드·마우스 입력을 가로채 상대 PC로 보내고, 상대 PC에서 같은 입력을 실행합니다.
  • 커서 넘기기. 상대 PC가 내 화면의 어느 쪽에 있는지 저장해 두고, 커서가 그 끝에 닿으면 조종 대상을 바꿉니다.
  • 기기와 연결 기록. 4자리 코드로 확인한 기기, 화면 배치, 연결 기록을 SQLite에 저장합니다.
