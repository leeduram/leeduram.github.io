개발 진행 중

멀티 PC 통합 제어 프로그램

같은 네트워크의 Windows PC 두 대를 키보드와 마우스 하나로 조종합니다. 커서를 화면 끝으로 밀면 상대 PC로 넘어가고, 상대 화면을 보며 조종하거나 파일을 주고받을 수 있습니다.

기술
C#, .NET 10, WPF, Win32 API, TCP/UDP, SQLite
구성
2인 팀. 입력 처리, 조종 세션, 화면, 로컬 DB, 테스트 담당
시험
노트북과 소형 PC 등 실제 기기 두 대로 반복 시험

핵심 구현

  • 입력 공유. 키보드·마우스 입력을 가로채 상대 PC로 보내고, 상대 PC에서 같은 입력을 실행합니다.
  • 커서 넘기기. 상대 PC가 내 화면의 어느 쪽에 있는지 저장해 두고, 커서가 그 끝에 닿으면 조종 대상을 바꿉니다.
  • 기기와 연결 기록. 4자리 코드로 확인한 기기, 화면 배치, 연결 기록을 SQLite에 저장합니다.

문제와 해결

연결이 끊기면 내 PC의 키보드·마우스가 먹통이 됨
정상 신호가 2초 동안 없으면 입력 막기를 자동으로 푸는 감시 기능을 넣음
두 PC가 같은 입력을 끝없이 주고받을 수 있음
프로그램이 만들어 낸 입력은 가로채지 않고 통과시키도록 설계

게임 총기 개조 시뮬레이터

게임 Delta Force의 총기 개조 화면을 웹에서 그대로 해 볼 수 있습니다. 데이터는 1시간마다 자동으로 갱신됩니다.

기술
PowerShell, MySQL, JavaScript, Node.js, Cloudflare Pages
구성
개인. 기획, 데이터 수집, DB, 화면, 배포, 운영 전체
규모
무기 69종, 테이블 26개, 저장 프로시저 8개

핵심 구현

  • 자동 수집과 배포. 작업 스케줄러가 1시간마다 데이터를 모아 MySQL에 쌓고, 화면용 데이터로 만들어 바뀐 파일만 배포합니다.
  • 서버별 패치 반영. 중국 서버와 글로벌 서버의 패치 시점이 달라, 글로벌 서버의 패치를 감지해 수치를 자동으로 전환합니다.
  • 화면. 총 이미지의 윤곽을 읽어 슬롯 위치를 잡고, 한국어·영어·중국어와 PC·모바일을 지원합니다.

문제와 해결

공식 데이터만으로는 정보가 부족함
다른 출처의 데이터와 비교해 맞는 쪽 값을 반영
기본 언어가 중국어라 한국어 이름이 없음
게임 화면을 직접 찍어 모으고 문자 인식으로 이름 데이터를 만듦
화면이 느리게 뜸
이미지를 동시에 불러오고 사이트에 함께 올려 개선

시각장애인 보행 도우미 앱

거리 센서 없이 휴대폰 카메라 한 대로 점자블록과 장애물을 인식해 빛과 소리로 알려 줍니다. 처음에는 카메라가 달린 스마트 안경을 구상했고, 같은 구조를 휴대폰으로 옮겨 검증했습니다.

기술
Flutter, YOLO 객체 인식 모델, 가속도·자이로 센서
구성
개인. 기획, 모델 학습, 야외 시험 전체
데이터
AI Hub 인도보행 영상 사진 113,205장

핵심 구현

  • 조각 학습. 점자블록을 위아래 12조각으로 나눠 학습시키고, 앱에서 곡선으로 이어 그립니다.
  • 센서 없는 거리 추정. 휴대폰 기울기와 카메라 높이로 거리를 계산해, 3m 안의 장애물을 경고합니다.
  • 방향 기억. 점자블록이 화면 밖으로 나가도 회전 각도를 계산해 방향을 표시합니다.

한계

  • 횡단보도와 신호등은 인식률이 낮아 실제로 쓸 수준이 아닙니다.
  • 야간과 우천 환경은 검증하지 못했습니다.
